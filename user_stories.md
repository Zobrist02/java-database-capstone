# Smart Clinic Management System: User Stories

## Admin User Stories

1. As an admin, I want to create and manage doctor accounts so that doctors can use the system.
2. As an admin, I want to view and manage patient accounts so that patient information stays organized.
3. As an admin, I want to view appointments so that I can help manage the clinic’s schedule.
4. As an admin, I want to control user access by role so that each person can use the features they need.
5. As an admin, I want to view a list of registered doctors so that I can check which doctors are available in the system.

## Patient User Stories

1. As a patient, I want to create an account and log in so that I can use the appointment portal.
2. As a patient, I want to browse doctors and their specialties so that I can choose a suitable doctor.
3. As a patient, I want to book an available appointment so that I can schedule a clinic visit.
4. As a patient, I want to view or cancel my appointments so that I can manage my schedule.
5. As a patient, I want to view prescriptions from my appointments so that I can follow my doctor’s instructions.

## Doctor User Stories

1. As a doctor, I want to log in securely so that I can access my clinic information.
2. As a doctor, I want to view my upcoming appointments so that I can plan my work.
3. As a doctor, I want to view relevant patient information for an appointment so that I can prepare for the visit.
4. As a doctor, I want to record a prescription for an appointment so that the patient can follow the treatment plan.
5. As a doctor, I want to update appointment status so that the clinic’s records stay current.
